# Diagnósticos legados

Estes scripts foram removidos de `tests/` porque são verificações manuais antigas, acessam o
ambiente local e não atendem ao contrato da suíte automatizada. Eles estão temporariamente
excluídos do Ruff enquanto são avaliados para saneamento ou remoção.

Não execute estes arquivos em terminais compartilhados: alguns ainda exibem valores de
configuração. Eles não fazem parte do quality gate e não podem ser usados como evidência de que uma
funcionalidade está validada.
